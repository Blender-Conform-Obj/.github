## 🧠 Overview

**Conform Object** is a specialized Blender add-on for adapting one mesh to the shape of another surface. It provides a focused set of projection and deformation tools that can reduce the amount of manual setup normally required when fitting geometry to curved, irregular, or complex forms.

The workflow is useful for placing panels, surface details, trims, plates, decorative elements, and other meshes onto existing objects. Projection behavior can be adjusted according to the direction and position of the source object, giving artists more control over how the geometry approaches the target surface.

Several conforming methods provide flexibility for different modeling situations. Grid-based projection, shrinkwrap-based deformation, gradient controls, and lattice deformation can be combined to achieve either localized adjustments or broader surface adaptation.

**Conform Object** is also designed around an editable Blender workflow. Modifier-based operations, normal transfer, vertex-weight visualization, reusable presets, and multi-object processing help artists manage repeated conforming tasks while continuing to refine the resulting geometry.

## 🚀 Key Features

| Feature | Description |
|----------|-------------|
| 🎯 **Surface Conforming** | Adapt selected geometry to the contours of a target object while maintaining an adjustable modeling workflow. |
| 🧭 **Directional Projection** | Use the source object's orientation to establish the direction from which geometry is projected toward the target. |
| 🟦 **Grid-Based Conforming** | Apply grid-oriented deformation for surfaces that require controlled distribution across the projected area. |
| 🧲 **Shrinkwrap Conforming** | Follow target geometry using a shrinkwrap-based approach for close surface adaptation. |
| 📊 **Gradient Influence** | Vary deformation strength across the object so selected regions can conform more strongly than others. |
| 🧱 **Lattice Shaping** | Introduce lattice deformation for broader and more flexible changes to the source object's form. |
| 🎨 **Normal Transfer** | Transfer surface normal information to improve shading consistency after geometry has been conformed. |
| 🔄 **Batch Object Processing** | Work with multiple source objects in a single workflow when several components need to follow the same surface. |
| ⚙️ **Modifier-Based Editing** | Keep the conforming process connected to Blender's modifier system for continued adjustment. |
| 👁️ **Weight Visualization** | Inspect deformation-related vertex weights directly in the viewport to better understand gradient influence. |
| 💾 **Reusable Presets** | Store frequently used settings and apply them again when working on similar conforming operations. |
| ↩️ **Apply or Revert Workflow** | Finalize a completed deformation or return to an editable setup when additional changes are necessary. |
| 📐 **Controlled Surface Fitting** | Adjust the relationship between source and target objects to achieve more predictable surface placement. |
| 🧩 **Complex Shape Support** | Work with curved, irregular, and detailed surfaces that would otherwise require extensive manual mesh manipulation. |
| 🏗️ **Production Modeling Utility** | Use conforming operations for product components, mechanical parts, architectural details, props, and other 3D assets. |

## Additional Information for Windows Users

**Conform Object** provides a practical way to fit separate pieces of geometry onto an existing Blender surface. It can be useful for panels, trims, plates, decorative components, and other details that need to follow the shape of a larger model.

Grid, Shrinkwrap, gradient, and lattice-based methods allow the deformation approach to be adapted to different surface conditions. Artists can control where the effect is applied and how strongly the source mesh changes.

Normal transfer, weight visualization, presets, and multi-object processing add further flexibility for larger modeling projects and repeated conforming tasks.

**Conform Object** brings surface projection and deformation controls together in a streamlined Blender workflow for precise 3D modeling.
